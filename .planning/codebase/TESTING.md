## Manual Verification Paths
Run `npm run dev`, open the Vite app, and verify the main tabs in `DosimetriaPenal.tsx`: Calculadora, Concurso, Lei, Súmulas, and Auditoria. In Calculadora, select or type a crime from `public/crimes.csv`, confirm penalty min/max/type/violence auto-fill, adjust vetores, agravantes, atenuantes, majorantes, minorantes, tentativa, detração, multa, and medida de segurança, then confirm `ResultadoFinal` and copied reports. In Concurso, add penalties, answer modality questions, apply the suggested modality, and copy the report.

## High Value Missing Tests
Unit tests for pure calculation utilities in `src/components/dosimetria/utils.ts` would provide the highest value: `fmt`, `prescPrazo`, `parseCrimeCSV`, `calcRegime`, `calcProgressao`, `calcConcurso`, `sugerirModalidadeConcurso`, and `generateRelatorio`. Component tests should cover `DosimetriaPenal` form flows, CSV loading fallback, and report copy success/failure paths. Regression tests should lock domain-sensitive edge cases such as atenuantes not reducing below the minimum, concurso material capped at 40 years, date/prescription calculations, and malformed CSV rows.

## Build And Typecheck Signals
TypeScript is strict and includes unused-local and unused-parameter checks for app code. `npm run build` should catch type errors, unused imports/variables, and bundling failures. Because there is no lint script, style consistency, accessibility issues, React hook dependency issues, and dead branches beyond TypeScript checks are not automatically enforced.

## Testability Constraints
Important calculation logic is split between pure helpers in `utils.ts` and inline derived values in `DosimetriaPenal.tsx`, so not all behavior can be unit-tested without rendering the component or extracting logic. The app depends on browser APIs (`fetch`, `navigator.clipboard`) that would need mocks in component tests. Form inputs store numeric values as strings, so tests should cover empty, invalid, zero, and localized-looking values. The CSV parser currently uses simple comma splitting and is not robust to quoted commas.
